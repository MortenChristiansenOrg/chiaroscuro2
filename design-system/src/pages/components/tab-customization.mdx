# Tab Customization

Built-in page for customizing individual tab appearance and behavior. Opens in-tab via context menu "Customize tab" action, replacing the tab's web content. Uses the shared `SettingsLayout` component for consistent styling with Settings and Domain Customization pages.

## Anatomy

1. **Header** — title "Tab Customization" with sliders icon, shared with SettingsLayout
2. **Category nav** — left sidebar showing "Appearance" category (scroll-spy)
3. **Appearance section** — category heading + setting items
4. **Custom title input** — text input pre-filled with current page title
5. **Address toggle** — toggle button for allowing address updates on pinned tabs
6. **Done button** — closes the customization view and returns to web content

## States

### Default (no customization)
Custom title input is empty (placeholder shows page title). Toggle shows "Disabled".

### With customization
Custom title input shows the saved custom title. Toggle reflects saved state. Sidebar tab title updates in real-time.

### No tab specified
Centered fallback text: "No tab specified." in `var(--muted-foreground)`.

---

## Behavior

- **Entry point**: Right-click tab in sidebar, select "Customize tab" from context menu
- **In-tab display**: Replaces the tab's WebContentsView with the built-in page (overlay approach — tab data is never modified)
- **Live updates**: Custom title changes update the sidebar tab label immediately
- **Auto-save**: All changes persist to RxDB via commands — no explicit save button needed
- **Title clearing**: Emptying the input clears the custom title (reverts to page title in sidebar)
- **Auto-cleanup**: Customizations are removed when the associated tab closes
- **Store cleanup**: When all customization values return to defaults, the persisted record is removed

## Accessibility

- Text input has `aria-label="Custom title"` and visible label text
- Toggle button has descriptive text label ("Enabled" / "Disabled")
- Semantic heading hierarchy: `<h1>` for title (in SettingsLayout), `<h2>` for category
- "Customize tab" context menu entry is not shown for built-in or ephemeral tabs

## Layout & Composition

```
TabCustomizationPage              # root, delegates to SettingsLayout
  SettingsLayout                  # shared layout (icon, title, category nav, scroll area)
    AppearanceSettings            # section#tab-customization-appearance
      h2                          # "APPEARANCE" category heading
      SettingItem                 # "Custom Title" — label + description + input
        input[type=text]          # custom title text input
      SettingItem                 # "Allow Address Updates" — label + description + toggle
        button                    # toggle (Enabled/Disabled)
    button                        # "Done" — closes view
```
