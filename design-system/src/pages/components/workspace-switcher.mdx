# Workspace Switcher

The workspace bar sits at the bottom of the sidebar. Contains colored bubble buttons for each workspace, plus edit and add controls.

## Workspace Bubbles

Each bubble uses the workspace's accent color derived from `var(--accent-hue)`. All accent colors share `L=var(--accent-L), C=var(--accent-C)` for consistent vibrancy.

<ComponentPreview label="Workspace Bubbles (dark bg)">
  <div style={{ background: "var(--window-bg)", borderRadius: "var(--radius-md)", padding: 12, display: "inline-flex", gap: 6, alignItems: "center" }}>

## Bubble Specs

| Property | Token/Value |
|----------|-------------|
| Size | `var(--click-target-min)` |
| Border radius | `--radius-full` |
| Font size | `--text-xs`-equivalent (10px), weight 600 |
| Background | `oklch(var(--accent-L) var(--accent-C) <hue>)` |
| Transition | `transform var(--duration-normal) var(--ease-in-out)` |

## Curated Accent Palette

See [Colors](/colors) for the full palette. Available hues: Iris (270), Ocean (230), Teal (195), Jade (160), Lime (130), Amber (85), Coral (45), Rose (350), Berry (320).

## States

| State | Effect |
|-------|--------|
| Hover | `transform: scale(1.12)` |
| Active | `transform: scale(1.08)`, Ring shadow: `0 0 0 2px oklch(var(--accent-L) var(--accent-C) <hue> / 0.4)` |

## Workspace Bar Layout

| Property | Token/Value |
|----------|-------------|
| Gap | `0.375rem` (related) |
| Position | `margin-top: auto` (pushed to bottom) |
| Controls | Edit + Add buttons, `margin-left: auto` |
| Keyboard | `←`/`→` to switch between workspaces |
