# Workspace Switcher

The workspace bar sits at the bottom of the sidebar. Contains colored bubble buttons for each workspace, plus edit and add controls.

---

## Anatomy

- **Bubble row** — horizontal list of colored circle buttons, one per workspace
- **Edit button** — icon button to enter workspace management mode
- **Add button** — icon button to create a new workspace

---

## Workspace Bubbles

Each bubble uses the workspace's accent color derived from `var(--accent-hue)`. All accent colors share `L=var(--accent-L), C=var(--accent-C)` for consistent vibrancy.

## Bubble Specs

| Property      | Token/Value                                           |
| ------------- | ----------------------------------------------------- |
| Size          | `var(--click-target-min)`                             |
| Border radius | `--radius-full`                                       |
| Font size     | `--text-xs`-equivalent (10px), weight 600             |
| Background    | `oklch(var(--accent-L) var(--accent-C) <hue>)`        |
| Transition    | `transform var(--duration-normal) var(--ease-in-out)` |

## Curated Accent Palette

See [Colors](/colors) for the full palette. Available hues: Flame (20), Amber (50), Gold (80), Lime (110), Green (140), Teal (180), Sky (205), Ocean (230), Indigo (255), Iris (280), Berry (315), Rose (350).

---

## States

| State                      | Effect                                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| Default (inactive)         | `transform: scale(0.75)`, semi-transparent background (`oklch(... / 0.2)`)                |
| Hover                      | `transform: scale(1.12)`                                                                  |
| Active (current workspace) | `transform: scale(1)`, full-opacity background, ring shadow: `0 0 0 2px oklch(... / 0.4)` |
| Disabled                   | `opacity: 0.4`, `cursor: default`                                                         |

---

## Behavior

- **Click:** switches to the clicked workspace immediately.
- **Tooltip:** each bubble shows workspace name on hover. Delay: 400ms.
- **Edit button:** opens workspace management panel.
- **Add button:** creates a new workspace with a default accent color.
- **No drag:** bubbles are not draggable (reorder via edit mode only).

---

## Animation & Motion

Scale transform on hover and active states:

```css
transition: transform var(--duration-normal) var(--ease-in-out);
```

- **Inactive → Active:** scale `0.75 → 1`, background opacity `0.5 → 1`, ring shadow fade-in.
- **Active → Inactive:** scale `1 → 0.75`, background opacity `1 → 0.5`, ring shadow fade-out.
- **Hover:** scale up to `1.12`.
- **`prefers-reduced-motion`:** transitions degrade to instant (`duration: 0`).

---

## Keyboard & Focus

- **Not keyboard-navigable.** All bubbles use `tabIndex={-1}`. Workspace switching is available via commands and keyboard shortcuts.

---

## Accessibility

- **`aria-label`:** required on each bubble (e.g., `aria-label="Work workspace"`).
- **`aria-current="true"`:** set on the active workspace bubble.
- **Semantic HTML:** use `<button type="button">`, never `<div>`.
- **Touch target:** minimum `var(--click-target-min)` (24px) in both dimensions.
- **Contrast:** accent backgrounds against white text must meet 3:1 minimum. The curated palette ensures this.

| Property  | Token/Value                                        |
| --------- | -------------------------------------------------- |

- No z-index concerns — sits in normal flow within sidebar.
