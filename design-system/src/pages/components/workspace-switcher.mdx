# Workspace Switcher

The workspace bar sits at the bottom of the sidebar. Contains icon buttons for each workspace, plus edit and add controls.

---

## Anatomy

- **Icon row** — horizontal list of icon buttons, one per workspace
- **Edit button** — icon button to enter workspace management mode
- **Add button** — icon button to create a new workspace

---

## Workspace Icons

Each workspace displays its icon (Font Awesome or text) without a background circle. Icons use a drop-shadow filter for depth against the sidebar background. The active icon is displayed at full size while inactive icons are scaled down.

<LivePreview label="Workspace Bubbles (dark bg)">
  <div
    style={{
      padding: 12,
      display: "inline-flex",
      alignItems: "center",
    }}
  >
    {DEMO_WORKSPACES.map((ws, i) => {
      const isActive = ws.id === workspaceId("ws-work");
      const prevActive = i > 0 && DEMO_WORKSPACES[i - 1]?.id === workspaceId("ws-work");
      const gap = i === 0 ? 0 : isActive || prevActive ? "0.125rem" : "0.0625rem";
      return (
        <div key={ws.id} style={{ marginLeft: gap, transition: "margin var(--duration-normal) var(--ease-in-out)" }}>
          <WorkspaceBubble workspace={ws} isActive={isActive} />
        </div>
      );
    })}
  </div>
</LivePreview>

## Icon Specs

| Property      | Token/Value                                           |
| ------------- | ----------------------------------------------------- |
| Size          | 32px                                                  |
| Font size     | 16px (FA icons), `--text-sm` (text icons, weight 600) |
| Background    | transparent                                           |
| Color         | `var(--glass-text-primary)`                           |
| Shadow        | `filter: drop-shadow(0 1px 3px rgba(0,0,0,0.5))`     |
| Transition    | `all var(--duration-normal) var(--ease-in-out)`       |

---

## States

| State                      | Effect                                               |
| -------------------------- | ---------------------------------------------------- |
| Default (inactive)         | `transform: scale(0.75)`, `opacity: 0.7`             |
| Hover                      | `transform: scale(1.2)`, `opacity: 1`                |
| Active (current workspace) | `transform: scale(1.1)`, `opacity: 1`                |
| Disabled                   | `opacity: 0.4`, `cursor: default`                    |

---

## Behavior

- **Click:** switches to the clicked workspace immediately.
- **Tooltip:** each bubble shows workspace name on hover. Delay: 400ms.
- **Double-click:** opens workspace editor for the clicked workspace.
- **Right-click:** context menu with edit/add actions.
- **No drag:** bubbles are not draggable (reorder via edit mode only).

---

## Animation & Motion

Scale transform on hover and active states:

```css
transition: all var(--duration-normal) var(--ease-in-out);
```

- **Inactive → Active:** scale `0.75 → 1.1`, opacity `0.7 → 1`.
- **Active → Inactive:** scale `1.1 → 0.75`, opacity `1 → 0.7`.
- **Hover:** scale up to `1.2`, opacity `1`.
- **`prefers-reduced-motion`:** transitions degrade to instant (`duration: 0`).

---

## Keyboard & Focus

- **Not keyboard-navigable.** All bubbles use `tabIndex={-1}`. Workspace switching is available via commands and keyboard shortcuts.

---

## Accessibility

- **`aria-label`:** required on each icon (e.g., `aria-label="Work workspace"`).
- **`aria-current="true"`:** set on the active workspace icon.
- **Semantic HTML:** use `<button type="button">`, never `<div>`.
- **Touch target:** minimum 32px in both dimensions.

---

## Layout & Composition

| Property  | Token/Value                                        |
| --------- | -------------------------------------------------- |
| Position  | `margin-top: auto` (anchored to bottom of sidebar) |
| Gap       | `0.125rem` active↔neighbor, `0.0625rem` inactive↔inactive (animated) |
| Direction | horizontal, `display: flex`, `align-items: center` |

- Sidebar collapse hides the workspace bar entirely.
- No z-index concerns — sits in normal flow within sidebar.
