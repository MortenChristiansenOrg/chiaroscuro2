# Extension Permissions

Implementation: `src/features/extensions/ExtensionPermissions.tsx`.

Displays the exact permission review tied to a staged package or installed manifest. Approval is disabled while busy. Declining leaves new code inactive. Access details expand through a native details element.

Uses existing card, border, background, foreground and muted text tokens. Buttons use the settings button dimensions and disabled semantics. Content wraps within the settings page.

[Extensions page](/components/extensions-page) provides the complete composition.
