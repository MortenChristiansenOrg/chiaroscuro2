# Extension Permissions

Implementation: `src/features/extensions/ExtensionPermissions.tsx`.

Requested access is visible by default in plain language, grouped by website access, tabs, clipboard, background activity, network requests and browser integration. Groups use two columns when space permits and one column in narrow content. **Exact permission
names** expands the original manifest entries, including unknown permissions.
The reviewed version and extension name remain visible. Updates label their added
access separately from a first install. Approval uses the exact reviewed package
token and is disabled during an operation.

Uses the shared card's border and surface tokens, a 1rem inset, 0.75rem section
gaps, and a 1rem group gap. The approval button is a primary action. The owning
installation card provides cancellation; leaving an update unapproved grants no
new access.
