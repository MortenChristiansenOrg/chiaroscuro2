# Extension Enabled Toggle

Implementation: `src/features/extensions/ExtensionEnabledToggle.tsx`.

Uses the extension management switch dimensions: 2rem × 1.125rem track, 0.875rem thumb, full rounding and primary/muted state colors. A native checkbox covers the control for mouse, touch and keyboard input. Focus outlines the track; disabled state prevents actions and reduces opacity. The visible Enabled label names the control.

Used by [InstalledExtensionCard](/components/installed-extension-card).
