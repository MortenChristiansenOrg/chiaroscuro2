# Sub-Tab Overlay

Popup overlay for links opened from within a tab. Appears as a floating content card over a dimmed backdrop — just raw web content, no chrome. Part of the content area, below native overlays (command palette, tooltips).

## Anatomy

1. **Backdrop** — full content-area dark overlay, dismisses on click
2. **Frame card** — rounded container with elevated shadow, holds the WebContentsView
3. **Action buttons** — white circular Close and Promote buttons, arranged vertically to the right of the frame

## States

### Button States

| State | Effect |
|-------|--------|
| Default | White background, dark gray icon |
| Hover | `scale(1.15)` with springy easing |
| Active/Pressed | `scale(0.95)` |

Hover/active transitions use `200ms cubic-bezier(0.34, 1.56, 0.64, 1)` for a springy feel. No color change on hover for either button.

---

## Behavior

- **Open trigger**: `target="_blank"` links and `window.open()` calls open a sub-tab instead of navigating the parent.
- **Ctrl+Click / Middle-click**: Bypasses sub-tab, opens a new standalone tab.
- **Backdrop click**: Dismisses the topmost sub-tab.
- **Escape key**: Dismisses the topmost sub-tab (registered as a local shortcut).
- **Stacking**: Opening a link from within a sub-tab pushes a new sub-tab onto the stack. Only the topmost is visible.
- **Promote**: Converts the sub-tab's WebContentsView into a standalone tab without page reload.
- **Parent close**: Closing the parent tab closes all its sub-tabs.
- **Tab switching**: Sub-tab stacks are hidden when switching to a different parent tab and restored when switching back.

## Animation & Motion

| Transition | Duration | Easing |
|-----------|----------|--------|
| Backdrop opacity | `var(--duration-normal)` | `var(--ease-out)` |
| Button scale | `200ms` | `cubic-bezier(0.34, 1.56, 0.64, 1)` (springy) |

`prefers-reduced-motion`: Backdrop transitions should be instant.

---

## Keyboard & Focus

| Key | Action |
|-----|--------|
| Escape | Dismiss topmost sub-tab |

Focus remains in the WebContentsView content. The overlay action buttons are mouse-only (keyboard users use Escape to dismiss).

---

## Accessibility

- Backdrop and frame have `pointer-events: auto` to capture clicks.
- Close button: `aria-label="Close sub-tab"`, `data-tip="Close"`.
- Promote button: `aria-label="Open as tab"`, `data-tip="Open as tab"`.
- Button size 48px exceeds `var(--click-target-min)` (24px) minimum.
- Sub-tab overlay uses `var(--z-overlay)` (100), below command palette (native BrowserWindow, always on top).

---

## Layout & Composition

| Property | Value |
|----------|-------|
| Parent | ContentArea (main content region) |
| Position | Absolute overlay within content area |
| Z-index | `var(--z-overlay)` (100) — below native overlays |
| Container | Flex row: frame (flex-1) + button column (48px) |
| Gap | `0.75rem` between frame and buttons |

The sub-tab WebContentsView is positioned by the main process to fill the entire frame card area.
