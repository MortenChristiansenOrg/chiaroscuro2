# Buttons

All buttons follow the [state ladder](/interaction) — transparent default, hover surface on hover, active surface on press.

## Icon Buttons

Minimum visual size: `1.5rem × 1.5rem`. Must have `aria-label` and `data-tip` for tooltip.

### Window Controls

Minimize, Maximize, Close — arranged in a horizontal row at the top-right of the titlebar.

| Property | Token/Value |
|----------|-------------|
| Border radius | `--radius-md` (0.5rem) |
| Default text | `oklch(1 0 0 / 0.4)` (muted) |
| Hover bg | `oklch(1 0 0 / 0.1)` (hover surface) |
| Hover text | `oklch(1 0 0 / 0.75)` |
| Close hover bg | `oklch(0.577 0.245 27.325)` (destructive) |
| Transition | `background-color 150ms ease-out, color 150ms ease-out` |

### Close Buttons

Close/delete buttons follow a special pattern:
- **Default:** muted text color, hidden until parent hover
- **Hover:** destructive color `oklch(0.577 0.245 27.325)`
- **Border radius:** `--radius-sm` (0.375rem)
- Exception: items with unsaved changes always show their close indicator

### Workspace Controls

Edit and Add buttons in the workspace bar. `1.5rem × 1.5rem`, `--radius-md`.
