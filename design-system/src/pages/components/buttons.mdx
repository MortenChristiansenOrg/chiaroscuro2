# Buttons

All buttons follow the [state ladder](/interaction) — transparent default, hover surface on hover, active surface on press.

## Icon Buttons

Minimum visual size: `var(--click-target-min)`. Must have `aria-label` and `data-tip` for tooltip.

Minimize, Maximize, Close — arranged in a horizontal row at the top-right of the titlebar.

### Close Buttons

Close/delete buttons follow a special pattern:
- **Default:** muted text color, hidden until parent hover
- **Hover:** destructive color `var(--destructive)`
- **Border radius:** `--radius-sm`
- Exception: items with unsaved changes always show their close indicator

### Workspace Controls

Edit and Add buttons in the workspace bar. `var(--click-target-min)`, `--radius-md`.

## States

Full state ladder for icon buttons. All variants follow the same progression unless noted.

| State | Background | Text | Additional |
|-------|-----------|------|------------|
| Default | `transparent` | `var(--glass-text-muted)` | — |
| Hover | `var(--glass-hover)` | `var(--glass-text-hover)` | `cursor: pointer` |
| Active / Pressed | `var(--glass-pressed)` | `var(--glass-text-pressed)` | immediate on `pointerdown` |
| Disabled | `transparent` | `var(--glass-text-hint)` | `cursor: default`, no hover |
| Focus-visible | current bg | current text | `outline: 2px solid accent; outline-offset: 2px` |

**Close button exception:** hover bg is `transparent`, hover text is `var(--destructive)`. No glass-hover background.

**Disabled nav buttons:** Back is disabled when no history; Forward is disabled when at head of history.

---

## Behavior

- **Click:** triggers the button's command (navigate, minimize, close, etc.)
- **Tooltip:** every icon button requires `data-tip` attribute. Delay: 400ms.
- **Close button reveal:** hidden by default, visible on parent element hover. Exception: unsaved-change indicator always visible.
- **Window close:** no confirmation unless unsaved data exists.
- **Nav disabled:** Back/Forward render as disabled when history stack is empty in that direction.
- **No drag:** buttons are not draggable.
- **No overflow:** icon-only, no text truncation concern.

---

## Animation & Motion

All state transitions use:

```css
transition: background-color var(--duration-fast) var(--ease-out),
            color var(--duration-fast) var(--ease-out);
```

- **Close button reveal:** `opacity 0 -> 1` on parent hover, same `--duration-fast` / `--ease-out`.
- **No keyframe animations** — buttons have no loading or spinning states.
- **`prefers-reduced-motion`:** transitions degrade to instant (`duration: 0`).

---

## Keyboard & Focus

- **Focus zone:** buttons belong to the focus zone of their parent region (titlebar, sidebar, workspace bar).
- **Tab:** moves focus between zones. Arrow keys move between sibling buttons within a zone.
- **Enter / Space:** activates the focused button (same as click).
- **Focus ring:** `:focus-visible` only — `2px solid accent`, `outline-offset: 2px`.
- **Tab order:** all buttons are natively focusable (`<button>`), no `tabindex` needed.
- **Focus return:** after action completes, focus stays on the button (window controls may lose focus if window state changes).

---

## Accessibility

- **`aria-label`:** required on every icon-only button (e.g., `aria-label="Close tab"`).
- **Semantic HTML:** use `<button type="button">`, never `<div>` or `<span>`.
- **Touch target:** minimum `var(--click-target-min)` (1.5rem / 24px) in both dimensions. Visual hit area may be larger via padding.
- **Contrast:** glass text muted (`opacity >= 0.4`) meets 3:1 for chrome interactive elements. Hover/active states exceed 3:1.
- **Disabled state:** use `disabled` attribute, not `aria-disabled`, so the button is removed from tab order.
- **No live regions:** button actions don't require `aria-live` announcements.

## Layout & Composition

| Placement | Parent | Positioning | Details |
|-----------|--------|-------------|---------|
| Window controls | Titlebar (right) | flex, flow | horizontal row, `gap: 2px` |
| Nav buttons | Titlebar (left) | flex, flow | horizontal row, `gap: 1px` |
| Close buttons | Tab / sidebar item | absolute (within relative parent) | right-aligned, vertically centered |
| Workspace controls | Workspace bar | flex, flow | bottom of sidebar |

- Buttons size to content (icon + padding); no stretch.
- No z-index concerns — buttons sit in normal flow within their parent.
- Sidebar collapse hides workspace controls entirely.
