# Buttons

All buttons follow the [state ladder](/interaction) — transparent default, hover surface on hover, active surface on press.

## Icon Buttons

Minimum visual size: `var(--click-target-min)`. Must have `aria-label` and `data-tip` for tooltip.

### Window Controls

Minimize, Maximize, Close — arranged in a horizontal row at the top-right of the titlebar.

| Property | Token/Value |
|----------|-------------|
| Border radius | `--radius-md` |
| Default text | `var(--glass-text-muted)` |
| Hover bg | `var(--glass-hover)` |
| Hover text | `var(--glass-text-hover)` |
| Close hover bg | `var(--destructive)` |
| Transition | `background-color var(--duration-fast) var(--ease-out), color var(--duration-fast) var(--ease-out)` |

### Close Buttons

Close/delete buttons follow a special pattern:
- **Default:** muted text color, hidden until parent hover
- **Hover:** destructive color `var(--destructive)`
- **Border radius:** `--radius-sm`
- Exception: items with unsaved changes always show their close indicator

### Workspace Controls

Edit and Add buttons in the workspace bar. `var(--click-target-min)`, `--radius-md`.
