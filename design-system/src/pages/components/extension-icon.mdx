# Extension Icon

Implementation: `src/features/extensions/ExtensionIcon.tsx`.

Displays a bounded installed raster icon in a 2.5rem square with a puzzle-piece fallback. Images use contain and recover when their URL changes.

Uses existing card, border, background, foreground and muted text tokens. Buttons use the settings button dimensions and disabled semantics. Content wraps within the settings page.

[Extensions page](/components/extensions-page) provides the complete composition.

Bitwarden uses a bundled official 128px raster icon before installation and as a fallback when the package icon is missing. Generic extension icons fall back to the puzzle symbol. The asset provenance is recorded beside the image.
