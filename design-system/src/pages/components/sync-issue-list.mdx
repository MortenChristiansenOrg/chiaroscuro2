# Sync Issue List

## Overview

`src/features/sync/SyncIssueList.tsx` lists the items sync couldn't settle on its own, inside the [Sync Settings Section](/components/sync-settings-section).

## Anatomy

1. Needs attention heading.
2. One bordered row per item: the item's name and what happened.
3. For a conflict, Keep this machine's version and Use the other machine's version.

## States

Renders nothing when no item needs attention. Conflict rows offer both choices; other rows only explain what happened, because they settle once the item changes (too large, refused) or the cause is fixed (not applied). Buttons are disabled while a choice is being applied.

## Variants

Kinds: `conflict`, `too-large`, `not-uploaded` and `not-applied`. Size limits come from the service's own message, never from the browser.

## Behavior

Choosing a version keeps it on every machine. If either version changed since the list was shown, the choice is refused with an explanation and the list refreshes.

## Animation & Motion

Control colors transition using `--duration-fast` / `--ease-out`; reduced motion removes transitions.

## Keyboard & Focus

Tab moves through each row's buttons in order.

## Accessibility

A named list ("Items that didn't sync") of rows with plain-text explanations; choices are semantic buttons with visible focus outlines.

## Layout & Composition

Rows stack with 0.5rem gaps; conflict buttons wrap on narrow widths.
