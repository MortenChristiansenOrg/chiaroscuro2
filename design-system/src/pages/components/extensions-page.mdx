# Extensions Page

Built-in page for managing Chrome extensions. Opens as a tab via `extensions:open` command. Allows searching the Chrome Web Store, installing extensions, and managing installed extensions (enable/disable/uninstall).

## Anatomy

1. **Page header** — title with puzzle-piece icon
2. **Chrome Web Store section** — search input + search results list
3. **Search result card** — icon, name, description, install button
4. **Installed section** — list of installed extension cards
5. **Installed extension card** — icon, name, version, toggle switch, uninstall button

## States

### Loading
Search shows "Searching..." text in `var(--muted-foreground)` while results are pending.

### Empty Search Results
"No extensions found for [query]" in `var(--muted-foreground)`.

### No Installed Extensions
"No extensions installed." guidance text in `var(--muted-foreground)`.

### Installing
Install button changes to "Installing..." with `var(--muted)` background. Disabled state.

### Install Failed
Error message appears below the extension name in `var(--destructive-foreground)`.

### Installed
Install button shows "Installed" with transparent background and border. Disabled state.

---

## Behavior

- **Debounced search**: Search query is debounced (400ms) before sending to main process.
- **Singleton tab**: Only one extensions tab can exist at a time.
- **Immediate toggle**: Enable/disable takes effect immediately on the session.
- **Immediate uninstall**: Extension is removed from session and disk on uninstall.
- **Image fallback**: Extension icons fall back to puzzle-piece icon on load error.

## Accessibility

- Search input has `placeholder` text for context
- Uninstall buttons have `aria-label` and `data-tip` for tooltip
- Toggle switch uses hidden `<input type="checkbox">` for native semantics
- Extension icons use `alt=""` (decorative)
- Semantic heading hierarchy: `<h1>` for title (via PageHeader), `<h2>` for sections
