# Tabs

Rounded sidebar tabs. Each is a list item with favicon, label, and close button.

## Anatomy

- **Favicon** — `1rem x 1rem`, circular clip (`--radius-full`), leading position.
- **Label text** — single-line, truncates with ellipsis on overflow.
- **Close button** — trailing, hidden by default, revealed on parent hover.

## Pattern

- Full-width click target with `0.375rem` vertical padding and `0.75rem` horizontal padding.
- Subtle rounded border radius (`--radius-md`).
- Favicon at `1rem × 1rem`, circular clip.
- `0.625rem` gap between icon and label.
- Single line of text, truncated with ellipsis on overflow.
- Follows the [state ladder](/interaction).

## State Tokens

| State | Background | Text | Weight | Shadow |
|-------|-----------|------|--------|--------|
| Default | transparent | `var(--glass-text-default)` | 400 | none |
| Hover | `var(--glass-hover)` | `var(--glass-text-hover)` | 400 | none |
| Active | `var(--glass-active)` | `var(--glass-text-primary)` | 500 | `var(--shadow-subtle)` |
| Disabled | transparent | `var(--glass-text-hint)` | 400 | none |

## Tab Types

Three tab types exist with different default text brightness:

| Type | Default text | Behavior |
|------|-------------|----------|
| Pinned | `var(--glass-text-default)` | Global, always visible as favicon-only |
| Bookmarked | `var(--glass-text-default)` | Per-workspace, in sidebar list |
| Ephemeral | `var(--glass-text-muted)` | Auto-expire after 8hr TTL |

## Behavior

- **Click** activates the tab and loads its content in the main view.
- **Close button** hidden by default, revealed on parent hover. Shifts to `var(--destructive)` on its own hover.
- **Text truncation** — label uses `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`.
- **Pinned tabs** render as favicon-only (no label, no close button).

## Animation & Motion

| Property | Transition |
|----------|------------|
| Background color | `background-color var(--duration-fast) var(--ease-out)` |
| Text color | `color var(--duration-fast) var(--ease-out)` |
| Entrance | `tab-in var(--duration-enter) var(--ease-enter)` — slides in from left with fade |

## Keyboard & Focus

- **Tab** moves focus into the sidebar tab list.
- **Enter** activates the focused tab.
- **Arrow Up / Arrow Down** moves focus between tabs within the sidebar list.
- **Delete** or **Backspace** closes the focused tab (if closeable).

## Accessibility

- Each tab uses `role="listitem"` within a `role="list"` sidebar container.
- Close button has `aria-label="Close tab"`.
- Tab items are not keyboard-focusable (`tabIndex={-1}`).
- Active tab indicated with `aria-selected="true"`.

## Layout & Composition

- Lives inside the [Sidebar](/components/sidebar) as a vertical list.
- Full-width within sidebar, with `0.375rem` horizontal margin.
- Rounded (`--radius-md`).
- Favicon + label + close button laid out with `display: flex; align-items: center; gap: 0.625rem`.
