# Tabs

Pill-shaped sidebar tabs. Each is a list item with favicon, label, and close button.

## Pattern

- Full-width click target with `0.25rem` vertical padding and `0.75rem` horizontal padding.
- Pill-shaped border radius (`--radius-pill`).
- Favicon at `1rem × 1rem`, circular clip.
- `0.625rem` gap between icon and label.
- Single line of text, truncated with ellipsis on overflow.
- Follows the [state ladder](/interaction).

## State Tokens

| State | Background | Text | Weight | Shadow |
|-------|-----------|------|--------|--------|
| Default | transparent | `var(--glass-text-default)` | 400 | none |
| Hover | `var(--glass-hover)` | `var(--glass-text-hover)` | 400 | none |
| Active | `var(--glass-active)` | `var(--glass-text-primary)` | 500 | `var(--shadow-subtle)` |
| Disabled | transparent | `var(--glass-text-hint)` | 400 | none |

## Tab Types

Three tab types exist with different default text brightness:

| Type | Default text | Behavior |
|------|-------------|----------|
| Pinned | `var(--glass-text-default)` | Global, always visible as favicon-only |
| Bookmarked | `var(--glass-text-default)` | Per-workspace, in sidebar list |
| Ephemeral | `var(--glass-text-muted)` | Auto-expire after 8hr TTL |

## Close Button

Hidden by default, visible on parent hover. Shifts to destructive color on its own hover. See [Buttons](/components/buttons).
