# Tabs

Pill-shaped sidebar tabs with favicon, label, and close button.

## Specs

| Property | Value |
|----------|-------|
| Padding | `5px 12px` |
| Margin | `1px 6px` |
| Border radius | `20px` (pill) |
| Favicon | `16×16px`, `border-radius: 50%` |
| Text size | `12.5px` |
| Gap | `10px` |
| Default text color | `oklch(1 0 0 / 0.55)` |
| Hover bg | `oklch(1 0 0 / 0.1)` |
| Hover text | `oklch(1 0 0 / 0.75)` |
| Active bg | `oklch(1 0 0 / 0.22)` |
| Active text | `oklch(1 0 0 / 0.95)`, weight `500` |
| Active shadow | `0 1px 4px oklch(0 0 0 / 0.05)` |
| Transition | `all 0.15s` |

## Ephemeral Tabs

Ephemeral tabs have dimmer text:

| Property | Value |
|----------|-------|
| Default text | `oklch(1 0 0 / 0.35)` |
| Hover text | `oklch(1 0 0 / 0.55)` |

## Folder Children

Tabs inside a folder group use `padding-left: 28px` to indent.
