# Supported Extension Card

Implementation: `src/features/extensions/SupportedExtensionCard.tsx`.

Offers the official Bitwarden package for review. Downloading never executes unapproved code. The button has a busy state and errors appear in the owning settings page.

Uses existing card, border, background, foreground and muted text tokens. Buttons use the settings button dimensions and disabled semantics. Content wraps within the settings page.

[Extensions page](/components/extensions-page) provides the complete composition.
