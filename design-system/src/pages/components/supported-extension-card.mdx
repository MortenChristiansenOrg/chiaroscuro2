# Supported Extension Card

Implementation: `src/features/extensions/SupportedExtensionCard.tsx`.

The same branded card covers discovery, download, permission review, and errors.
**Review and install** downloads the official package without running it. Progress
explains that approval is still required. The permission review appears inline;
**Approve and install** is the only action that installs it. **Cancel installation**
discards a staged package directly. Failed downloads expose **Retry download**.

Cards use a 1.25rem inset, 1rem vertical gaps, and the shared
[ExtensionCardHeader](/components/extension-card-header). The action and explanation
wrap together without crowding the title. Status changes use `role=status`;
errors use `role=alert`. Installation never proceeds without explicit approval.
