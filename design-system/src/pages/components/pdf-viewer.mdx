# PDF Viewer

A custom PDF reader that replaces Chromium's built-in viewer. Supports two rendering backends (pdf.js, mupdf) selectable in settings. Includes a user-editable index sidebar, search, zoom, and virtual scrolling for large documents.

---

## Anatomy

- **Toolbar** -- index toggle, page navigation (up/down + input), zoom controls (minus/percent/plus), search (input + match count + prev/next)
- **Index sidebar** -- header with "Index" label and add button, scrollable list of draggable entries (grip icon, label, page number, delete button)
- **Page viewport** -- scrollable area with canvas-rendered PDF pages, search highlight overlay

## Behavior

- **PDF interception** -- any navigation to a `.pdf` URL is intercepted and opened in this viewer as a built-in page.
- **Backend selection** -- settings toggle chooses between pdf.js and mupdf. Change applies to next PDF opened.
- **Virtual scrolling** -- only visible pages + 1-viewport buffer are rendered. Canvases are created/destroyed as pages enter/leave the viewport.
- **HiDPI rendering** -- canvas pixel dimensions scaled by `devicePixelRatio` for crisp rendering.
- **Index persistence** -- custom index stored by `{filename}:{hash}` key. Moving/copying a PDF preserves the index.
- **Index auto-populate** -- on first open, the PDF's built-in outline is imported as index entries.
- **Search highlighting** -- matches shown as semi-transparent overlays on a separate canvas layer. Current match page uses orange, others yellow.

## Keyboard & Focus

| Key | Action |
|-----|--------|
| Enter (in search) | Next match |
| Shift+Enter (in search) | Previous match |
| Escape (in search) | Clear search |
| Enter (in page input) | Go to page |
| Enter (on index entry) | Navigate to entry's page |

## Accessibility

- All icon-only buttons have `data-tip` and `aria-label`.
- Search input, page input have `aria-label`.
- Index entries are focusable (`tabIndex={0}`) with keyboard navigation.
- Buttons meet `--click-target-min` (24px) minimum size.

---

## Layout & Composition

- Renders as a built-in page (`app:pdf-reader?url=...`) inside the content area.
- Full height flex column: toolbar (flex-shrink 0) + body (flex row: sidebar + viewport).
- Sidebar is conditionally rendered based on toggle state.
- Z-index: content level (`--z-base`).
- Parent: [Web Content Host](/components/web-content-host) via BuiltInPage system.
