# Tooltips

Tooltips use a `[data-tip]` attribute system — any element with `data-tip="text"` gets a tooltip on hover.

## Implementation

A `TooltipLayer` component listens to global `mouseover` events, finds the nearest `[data-tip]` ancestor, and renders a positioned portal.

## Visual Specs

| Property | Token/Value |
|----------|-------------|
| Background | `oklch(0.16 0 0 / 0.92)` |
| Backdrop filter | `blur(var(--glass-backdrop-blur))` |
| Color | `oklch(0.88 0 0)` |
| Font size | `--text-sm` |
| Font weight | 500 |
| Letter spacing | `0.01em` |
| Border radius | `--radius-sm` |
| Delay | `400ms` |

## Animation

Follows the [overlay pattern](/motion):
- Enter with `--duration-enter` at `scale(0.96)` → `scale(1)`, `opacity: 0` → `1`
- Exit with `--duration-exit`, reverse

```css
@keyframes tip-in {
  from { opacity: 0; scale: 0.96; }
  to { opacity: 1; scale: 1; }
}
```

## Usage

```html
<button data-tip="Copy URL">...</button>
```

No wrapper component needed — just add the attribute. Every icon-only button must have `data-tip`.

## Positioning

Fixed, centered below trigger. Flips above if near viewport bottom. Does not trap focus.
