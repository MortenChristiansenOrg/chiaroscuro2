# Tooltips

Tooltips use a `[data-tip]` attribute system — any element with `data-tip="text"` gets a tooltip on hover. A floating label, no arrow.

## Anatomy

Simple atomic component — a single text container rendered as a fixed-position portal by `TooltipLayer`. No arrow, no close button, no interactive content.

## Visual Specs

| Property | Token/Value |
|----------|-------------|
| Background | `oklch(0.16 0 0 / 0.92)` |
| Backdrop filter | `blur(var(--glass-backdrop-blur))` |
| Color | `oklch(0.88 0 0)` |
| Font size | `--text-sm` |
| Font weight | 500 |
| Letter spacing | `0.01em` |
| Border radius | `--radius-sm` |
| Padding | `4px 8px` |
| Delay | `400ms` |

## States

Tooltips are non-interactive. Two states only:

| State | Visibility | Trigger |
|-------|-----------|---------|
| Hidden | not rendered | default |
| Visible | rendered + animated in | hover or focus on `[data-tip]` element after 400ms delay |

No hover, active, disabled, or selected states — the tooltip itself is never interactive.

## Implementation

A `TooltipLayer` component listens to global `mouseover` events, finds the nearest `[data-tip]` ancestor, and renders a positioned portal.

## Behavior

- **Appear:** shows after 400ms hover delay on any `[data-tip]` element
- **Dismiss:** hidden immediately on `mouseleave`, `click`, or `scroll`
- **Follow target:** tooltip is positioned relative to the trigger element, not the cursor
- **No interaction:** tooltip content is not selectable, clickable, or focusable
- **No overflow:** text is single-line, no truncation expected (keep labels short)

## Animation

Follows the [overlay pattern](/motion):
- Enter with `--duration-enter` at `scale(0.96)` -> `scale(1)`, `opacity: 0` -> `1`
- Exit with `--duration-exit`, reverse
- `prefers-reduced-motion`: degrades to instant (duration: 0)

```css
@keyframes tip-in {
  from { opacity: 0; scale: 0.96; }
  to { opacity: 1; scale: 1; }
}
```

## Keyboard & Focus

- **Focus trigger:** tooltip appears on `focusin` of a `[data-tip]` element (same delay as hover)
- **Focus dismiss:** tooltip hidden on `focusout`
- **Not focusable:** the tooltip itself is never in the tab order
- **No key bindings:** no Escape handling needed (tooltip is non-interactive)

## Accessibility

- **`role="tooltip"`** on the tooltip element
- **`aria-describedby`** on the trigger element, pointing to the tooltip's `id`
- **Not focusable:** tooltip is supplementary text, not an interactive element
- **Contrast:** text `oklch(0.88 0 0)` on `oklch(0.16 0 0 / 0.92)` bg exceeds 4.5:1
- **No live region:** tooltip appearance is already announced via `aria-describedby` association

## Layout & Composition

| Property | Value |
|----------|-------|
| Positioning | `position: fixed`, portal rendered outside component tree |
| Alignment | centered horizontally below trigger |
| Flip | repositions above trigger if near viewport bottom |
| Z-index | `var(--z-tooltip)` |

No responsive behavior — tooltips size to content and are viewport-aware via flip logic.

## Usage

```html
<button data-tip="Copy URL">...</button>
```

No wrapper component needed — just add the attribute. Every icon-only button must have `data-tip`.
