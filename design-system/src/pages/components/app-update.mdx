# App Update

Two UI elements from the installer feature: a sidebar notification when an update is downloaded and ready, and a modal dialog when a page requests to open an external protocol.

---

## Update Notification

Compact inline notification in the sidebar indicating a new version is downloaded and ready to install.

### Anatomy

- **Update icon** — `download` while downloading, `arrow-up-from-bracket` when ready; default text color
- **Version label** — "Downloading v\{version\}…" or "v\{version\} ready", truncated, `--text-sm`
- **Restart button** — bordered ghost button, only shown when downloaded, triggers `installer:apply-update`
- **Dismiss button** — icon-only `xmark`, triggers `installer:dismiss-update`

## Protocol Dialog

Modal overlay shown when a web page requests to open an external protocol (e.g., `slack://`, `spotify://`, OAuth callbacks).

### Anatomy

- **Backdrop** — fixed overlay, `oklch(0 0 0 / 0.4)`
- **Card** — centered, max-width `26rem`, elevated shadow
- **Header row** — `arrow-up-right-from-square` icon + "Open external application?" title
- **Description** — origin hostname in bold + protocol in `<code>` block
- **Action buttons** — right-aligned: Deny (ghost), Always allow (ghost), Allow once (primary)

## Behavior

- **Update notification** — appears when `installer:update-available` event fires (showing download progress); transitions to "ready" when `installer:update-downloaded` fires. Re-appears on each new update even if previously dismissed.
- **Protocol dialog** — blocks interaction with the app until user responds; dismisses on any action (deny/allow).
- **"Always allow"** — persists the protocol+origin pair so future requests from the same origin are auto-allowed.

## Keyboard & Focus

- Restart and Dismiss buttons are native `<button>` elements.
- Protocol dialog buttons are focusable; "Allow once" is the primary action.
- `tabIndex={-1}` on update notification buttons (sidebar context).

---

## Accessibility

- Restart button: `aria-label="Restart to apply update"`, `data-tip="Restart to apply update"`.
- Dismiss button: `aria-label="Dismiss update notification"`, `data-tip="Dismiss"`.
- Protocol dialog buttons use semantic text labels (no icon-only buttons).
- Dialog origin hostname extracted from URL for readable display.

---

## Layout & Composition

- **Update notification** — rendered in the [Sidebar](/components/sidebar), typically near the bottom.
- **Protocol dialog** — rendered in the overlay zone (fixed positioning, above all content).
