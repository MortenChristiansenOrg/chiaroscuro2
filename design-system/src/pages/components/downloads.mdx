# Downloads

Section in the sidebar that shows active and recently completed file downloads with progress, pause/resume, and cancel controls.

---

## Anatomy

- **Section container** — bordered top, vertical stack
- **Section header** — uppercase label with arrow-down icon
- **Download item** — horizontal flex row: status icon, filename + progress bar, action buttons
- **Progress bar** — thin accent-colored bar inside a glass-border track
- **Action buttons** — pause/resume toggle + cancel (icon-only, `--click-target-min` sized)

## Behavior

- **Progress updates** — receivedBytes updates arrive throttled (500ms) from the main process; the bar width transitions smoothly via `--duration-fast`.
- **Pause/Resume toggle** — single button swaps between `pause` and `play` icons based on download state.
- **Cancel** — removes the download from the active set on the main side; UI receives a completed event with `"cancelled"` state.
- **Auto-remove** — completed/cancelled downloads disappear after 3 seconds.
- **Empty state** — the entire section is hidden when no downloads exist.
- **Save path** — files are saved to the user's desktop by default.

---

## Animation & Motion

- Progress bar width: `transition: width var(--duration-fast) var(--ease-out)`
- Completed opacity: `transition: opacity var(--duration-normal) var(--ease-in-out)`
- Button color/bg: `transition: color var(--duration-fast), background var(--duration-fast)`

---

## Keyboard & Focus

- Pause/Resume and Cancel buttons are native `<button>` elements, focusable via Tab.
- `tabIndex={-1}` — buttons are excluded from main tab order (sidebar scroll is primary focus).
- Standard `:focus-visible` ring when focused via keyboard.

---

## Accessibility

- Pause/Resume button has `aria-label` ("Pause download" / "Resume download") and `data-tip`.
- Cancel button has `aria-label="Cancel download"` and `data-tip="Cancel"`.
- Status icon changes from `arrow-down` (active) to `circle-check` (done) for visual distinction.
- Completed items at 0.5 opacity maintain text contrast above 3:1.

---

## Layout & Composition

- Rendered inside the [Sidebar](/components/sidebar), between the scrollable tabs area and the [Workspace Switcher](/components/workspace-switcher).
- Only visible when `downloads.size > 0`.
- Separated from tabs by a `var(--glass-border)` top border.
