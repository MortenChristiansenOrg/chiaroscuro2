# Downloads

Transient section in the sidebar showing active and recently completed file downloads. Each download is a micro-card whose accent-colored background fill visualizes progress — the card itself is the progress bar.

---

## Anatomy

- **Section divider** — label on left ("Downloads" with arrow-down icon), glass-border line extending right
- **Download card** — rounded container (`--radius-md`) with overflow hidden
- **Progress fill** — positioned absolutely, accent-colored at low opacity, width tracks progress %
- **Status icon** — `arrow-down` (active) or `circle-check` (completed)
- **File info** — filename (truncated, `--text-sm`) + byte progress in monospace (`--text-xs`)
- **Percentage badge** — right-aligned, fades on hover to reveal controls
- **Action buttons** — pause/resume + cancel, hidden by default, appear on hover

## Behavior

- **Progress fill** — accent-colored background fills from left based on `receivedBytes / totalBytes`; transitions via `--duration-fast`.
- **Hover reveal** — percentage badge fades out, pause/resume + cancel buttons fade in.
- **Pause breathing** — paused downloads' fill pulses via `dl-pulse` keyframe (2.5s ease-in-out infinite).
- **Completion** — fill transitions to 100% width at reduced opacity; item fades to 0.4 opacity.
- **Auto-remove** — completed/cancelled downloads removed after 3 seconds.
- **Empty state** — entire section hidden when no downloads exist.
- **File sizes** — displayed as human-readable bytes (e.g. "45 MB / 100 MB").

## Animation & Motion

| Element | Animation |
|---------|-----------|
| Card entrance | `dl-in var(--duration-enter) ease-enter both` — translateX(-6px) + opacity |

| Paused breathing | `dl-pulse 2.5s ease-in-out infinite` — opacity 1 → 0.4 → 1 |
| Completed fade | `transition: opacity var(--duration-normal) var(--ease-in-out)` |
| Control reveal | `transition: opacity var(--duration-fast)` |
| Button hover | `transition: color var(--duration-fast), background-color var(--duration-fast)` |

## Keyboard & Focus

- Pause/Resume and Cancel buttons are native `<button>` elements.
- `tabIndex={-1}` — excluded from main tab order (sidebar scroll is primary focus).
- Standard `:focus-visible` ring when focused via keyboard.

---

## Accessibility

- Pause/Resume button has `aria-label` ("Pause download" / "Resume download") and `data-tip`.
- Cancel button has `aria-label="Cancel download"` and `data-tip="Cancel"`.
- Progress fill has `aria-hidden` to prevent screen reader noise.
- Status icon changes from `arrow-down` (active) to `circle-check` (done) for visual distinction.
- Completed items at 0.4 opacity maintain text contrast above 3:1.
- File size info provides progress context for non-visual users.

---

## Layout & Composition

- Rendered inside the [Sidebar](/components/sidebar), between the scrollable tabs area and the [Workspace Switcher](/components/workspace-switcher).
- Only visible when `downloads.size > 0`.
- Separated from tabs by a divider line matching the ephemeral divider pattern.
- Section header follows the label + extending line pattern.
