## Animated Loading Border

Uses `@property --url-angle` with a `conic-gradient` masked to only show the border edge:

| Property | Value |
|----------|-------|
| `::before` inset | `-1.5px` |
| `::before` border-radius | `13.5px` |
| `::before` padding | `1.5px` (creates the border width) |
| Gradient color | `oklch(0.65 0.15 270 / 0.8)` (accent glow) |
| Gradient arc | `0%→10%→22%` (small bright arc) |
| Animation | `url-spin 2.5s linear infinite` |
| Mask | XOR composite to cut out the fill, leaving only border |
