# Address Bar

The URL "pill" sits centered in the titlebar with an animated loading border, domain customization and copy buttons. Clicking the address opens it for editing in the command palette.

The inactive Find bar is removed from layout. Opacity and `pointer-events: none` alone do not remove Electron native drag regions and can block these buttons on Windows. Icon centers and padding must remain hovered and clickable before and after using Find. Web pages in tabs cannot add drag regions of their own, so a site's `app-region: drag` never covers these buttons either.

## Anatomy

1. **Pill container** — rounded background housing URL and button
2. **Address button** — the monospace address; clicking it opens the command palette on the full address to edit it
3. **Copy button** — icon-only button to copy URL to clipboard
4. **Domain customization button** — sliders icon opening settings for the active web domain
5. **Zoom indicator** — adjacent percentage reset button, visible when web zoom differs from 100%; see [Zoom Indicator](/components/zoom-indicator)
6. **Loading ring** — conic-gradient border animation shown during page load

## Behavior

- **Domain customization.** The sliders button is visible for HTTP(S) pages and opens the active domain’s settings. Its default, hover, and pressed colors follow the glass icon-button states; it has no copied-confirmation state.

- **Edit address.** Clicking the address opens the command palette on the active tab's full address (for a PDF, the PDF's address), all of it selected, so typing replaces it. Enter goes there in the current tab; Escape, or Enter on an unchanged address, leaves the tab as it was. Built-in pages (Settings, the PDF reader) have no web page to replace, so their edits open in a new tab. The address has no tooltip: its text names it, and a tooltip would cover the page below.
- **Monospace for URL display.** Uses `--font-mono` (JetBrains Mono) for the URL text.
- **Copy to clipboard.** Copy button writes current URL to clipboard and shows check icon confirmation.
- **No drag.** Pill is not draggable.

## Animation & Motion

Uses `@property --url-angle` with a `conic-gradient` masked to the border edge. See [Motion & Animation](/motion) for the spinning gradient implementation.

| Animation | Duration | Easing | Details |
|-----------|----------|--------|---------|
| Loading spinner | `2.5s` | `linear` | `url-spin` keyframe, infinite loop, conic-gradient rotates `--url-angle` |
| Copy confirmation | `1.5s` | — | icon swaps `fa-copy` -> `fa-check`, `copy-confirm` scale-pop (`--duration-normal`, `--ease-out`), accent color + 12% accent bg, reverts after timeout |
| State transitions | `var(--duration-fast)` | `var(--ease-out)` | background-color, color |
| `prefers-reduced-motion` | `0` | — | spinner pauses, transitions instant |

## Keyboard & Focus

- **Pill controls are not keyboard-navigable.** The URL pill elements use `tabIndex={-1}`. Interaction is mouse/trackpad only; URL copying is available via command palette or keyboard shortcut, and the command palette (Ctrl+T) navigates by keyboard. The adjacent zoom indicator is keyboard-navigable and supports Enter/Space to reset.

---

## Accessibility

- **`aria-label`:** `Edit URL, <address>` on the address button, `Copy URL` on the copy button and `Domain customization` on the sliders button. All are semantic buttons.
- **Copy confirmation:** tooltip/`aria-live="polite"` announces "Copied" after clipboard write.
- **Semantic HTML:** the address, copy and domain customization controls are `<button type="button">`.
- **Touch target:** copy button meets `var(--click-target-min)` (1.375rem padded to 1.5rem).
- **Contrast:** glass text default meets 4.5:1 for body text; muted icon meets 3:1 for interactive elements.

## Layout & Composition

| Property | Value |
|----------|-------|
| Position | Absolute center in titlebar (flex: 1, centered content) |
| Z-index | None — within normal chrome flow |
| Resize | Pill truncates URL with ellipsis when titlebar narrows |
| Minimum width | Copy button + padding always visible; URL truncates first |

- Pill sits between nav buttons (left) and window controls (right) in the titlebar flex layout.
- Loading ring is a pseudo-element on the pill container, no extra DOM node.
