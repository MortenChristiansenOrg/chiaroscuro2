# Address Bar

The URL "pill" sits centered in the titlebar with an animated loading border and a copy button.

## Anatomy

1. **Pill container** — rounded background housing URL and button
2. **URL text** — monospace text with select-all behavior
3. **Copy button** — icon-only button to copy URL to clipboard
4. **Loading ring** — conic-gradient border animation shown during page load

## States

| State | Pill | Copy Button | Additional |
|-------|------|-------------|------------|
| Default | `var(--glass-subtle)` bg | `var(--glass-text-muted)` icon | idle, no border animation |
| Hover (pill) | `var(--glass-hover)` bg | unchanged | cursor: pointer |
| Loading | `var(--glass-subtle)` bg | unchanged | spinning conic-gradient border ring |
| Copied | unchanged | icon swaps to `fa-check`, accent color, accent bg at 12% opacity, scale-pop animation | check icon shown for 1.5s, then reverts to copy icon |
| Hover (copy btn) | unchanged | `var(--glass-hover)` bg, `var(--glass-text-hover)` icon | cursor: pointer |

---

## Behavior

- **Select-all on focus.** When the URL bar gains focus, all text is selected so the user can immediately type a replacement.
- **Monospace for URL display.** Uses `--font-mono` (JetBrains Mono) for the URL text.
- **Copy to clipboard.** Copy button writes current URL to clipboard and shows check icon confirmation.
- **No drag.** Pill is not draggable.

---

## Animation & Motion

Uses `@property --url-angle` with a `conic-gradient` masked to the border edge. See [Motion & Animation](/motion) for the spinning gradient implementation.

| Animation | Duration | Easing | Details |
|-----------|----------|--------|---------|
| Loading spinner | `2.5s` | `linear` | `url-spin` keyframe, infinite loop, conic-gradient rotates `--url-angle` |
| Copy confirmation | `1.5s` | — | icon swaps `fa-copy` -> `fa-check`, `copy-confirm` scale-pop (`--duration-normal`, `--ease-out`), accent color + 12% accent bg, reverts after timeout |
| State transitions | `var(--duration-fast)` | `var(--ease-out)` | background-color, color |
| `prefers-reduced-motion` | `0` | — | spinner pauses, transitions instant |

## Keyboard & Focus

- **Pill itself:** not directly keyboard-focusable (click-only interaction for URL selection).
- **Copy button:** natively focusable `<button>`, reachable via Tab.
- **Enter / Space:** activates copy button when focused.
- **Focus ring:** `:focus-visible` on copy button — `2px solid accent`, `outline-offset: 2px`.
- **Focus return:** focus stays on copy button after copy action.

---

## Accessibility

- **`aria-label`:** required on copy button (e.g., `aria-label="Copy URL"`).
- **Copy confirmation:** tooltip/`aria-live="polite"` announces "Copied" after clipboard write.
- **Semantic HTML:** copy uses `<button type="button">`, URL text in a `<span>`.
- **Touch target:** copy button meets `var(--click-target-min)` (1.375rem padded to 1.5rem).
- **Contrast:** glass text default meets 4.5:1 for body text; muted icon meets 3:1 for interactive elements.

---

## Layout & Composition

| Property | Value |
|----------|-------|
| Position | Absolute center in titlebar (flex: 1, centered content) |
| Z-index | None — within normal chrome flow |
| Resize | Pill truncates URL with ellipsis when titlebar narrows |
| Minimum width | Copy button + padding always visible; URL truncates first |

- Pill sits between nav buttons (left) and window controls (right) in the titlebar flex layout.
- Loading ring is a pseudo-element on the pill container, no extra DOM node.
