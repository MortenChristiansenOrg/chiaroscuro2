## Pill Container

| Property | Token/Value |
|----------|-------------|
| Position | Absolute center in titlebar |
| Border radius | `--radius-lg` |
| Background | `var(--glass-subtle)` |
| Hover bg | `var(--glass-hover)` |
| Font size | `--text-sm` |
| Color | `var(--glass-text-default)` |

## Behavior

- **Select-all on focus.** When the URL bar gains focus, all text is selected so the user can immediately type a replacement.
- **Monospace for URL display.** Uses `--font-mono` (JetBrains Mono) for the URL text.

## Animated Loading Border

Uses `@property --url-angle` with a `conic-gradient` masked to the border edge. See [Motion & Animation](/motion) for the spinning gradient implementation.

| Property | Value |
|----------|-------|
| Gradient color | Accent glow: `oklch(var(--accent-L) var(--accent-C) var(--accent-hue) / 0.8)` |
| Animation | `url-spin 2.5s linear infinite` |
