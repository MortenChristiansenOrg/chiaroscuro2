## Icon Properties

All icons share a base config:

```tsx
const S = {
  width: 10, height: 10,
  fill: "none",
  stroke: "currentColor",
  strokeWidth: 1.5
};
```

Some icons override size and strokeWidth. Favicon-type icons use `width/height: 9–12px` with `strokeWidth: 2`.
