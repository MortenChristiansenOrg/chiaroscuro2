# Icons

All icons must use the typed `<Icon>` component. Bare `<i>` FA classes are caught by the lint check.

Use **Font Awesome 7 Free** for all icons. No inline SVGs. Icons inherit `color` from their parent and scale with `font-size`.

## Available Styles (Free)

| Style | Class prefix | Use for |
|-------|-------------|---------|
| Solid | `fa-solid` | Primary UI actions, navigation, status |
| Regular | `fa-regular` | Secondary/outlined variants |
| Brands | `fa-brands` | Third-party logos |

## Usage

```tsx
{/* Basic icon (defaults to solid) */}
<Icon name="chevron-left" />

{/* Sized via css prop */}
<Icon name="folder" css={{ fontSize: "0.625rem" }} />

{/* Regular style */}
<Icon name="copy" style="regular" />

{/* Brands */}
<Icon name="github" style="brands" />

{/* Icon button (must have aria-label + data-tip) */}
<button aria-label="Close tab" data-tip="Close tab">
  <Icon name="xmark" />
</button>
```

## Icon Button Pattern

Every icon-only button must have `aria-label` and `data-tip` for the tooltip. Minimum visual size: `1.5rem × 1.5rem` (hit area may be larger via padding).

## Sizing

Icons inherit `font-size`. Default UI icon size is `0.625rem` (10px). Use the `css` prop or let it inherit from the parent.

| Context | Size |
|---------|------|
| Default UI | `0.625rem` (10px) |
| Navigation buttons | `0.6875rem` (11px) |
| Large / hero | `1rem`+ |
