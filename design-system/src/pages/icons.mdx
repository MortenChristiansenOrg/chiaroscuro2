# Icons

Use **Font Awesome 7 Free** for all icons. No inline SVGs, no custom icon components. Icons inherit `color` from their parent and scale with `font-size`.

**CDN (design system site):**
```html
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.0.1/css/all.min.css" />
```

**App (Electron):** install `@fortawesome/fontawesome-free` via npm/bun and import `@fortawesome/fontawesome-free/css/all.min.css` in the renderer entry.

## Available Styles (Free)

| Style | Class prefix | Use for |
|-------|-------------|---------|
| Solid | `fa-solid` | Primary UI actions, navigation, status |
| Regular | `fa-regular` | Secondary/outlined variants |
| Brands | `fa-brands` | Third-party logos |

## Usage

```html
<!-- Basic icon -->
<i class="fa-solid fa-chevron-left"></i>

<!-- Sized via font-size -->
<i class="fa-solid fa-folder" style="font-size: 0.625rem"></i>

<!-- Icon button (must have aria-label + data-tip) -->
<button aria-label="Close tab" data-tip="Close tab">
  <i class="fa-solid fa-xmark"></i>
</button>
```

## Icon Button Pattern

Every icon-only button must have `aria-label` and `data-tip` for the tooltip. Minimum visual size: `1.5rem × 1.5rem` (hit area may be larger via padding).

## Sizing

Icons inherit `font-size`. Default UI icon size is `0.625rem` (10px). Use `font-size` on the `<i>` element or let it inherit from the parent.

| Context | Size |
|---------|------|
| Default UI | `0.625rem` (10px) |
| Navigation buttons | `0.6875rem` (11px) |
| Large / hero | `1rem`+ |
