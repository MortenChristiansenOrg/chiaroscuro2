# Icons

All icons are inline SVGs — no icon library dependency. Each is a minimal functional component.

Icons at `0.625rem` (10px) default, stroke-based (`fill: none`, `stroke: currentColor`, `stroke-width: 1.5`). They inherit text color; opacity is controlled by parent state.

## Icon Button Pattern

Every icon-only button must have `aria-label` and `data-tip` for the tooltip. Minimum visual size: `1.5rem × 1.5rem` (hit area may be larger via padding).

## Base Config

```tsx
// Default icon properties
fill: "none"
stroke: "currentColor"
strokeWidth: 1.5
// Size: 0.625rem (10px) default
```
