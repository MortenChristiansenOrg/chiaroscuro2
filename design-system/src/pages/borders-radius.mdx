# Geometry & Borders

## Border Radius Scale

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | `0.375rem` (6px) | Small controls (close button, badges) |
| `--radius-md` | `0.5rem` (8px) | Medium controls (nav buttons, toolbar items, window controls) |
| `--radius-lg` | `0.75rem` (12px) | Containers (URL pill, cards, panel corners) |
| `--radius-full` | `50%` | Circles (favicons, workspace bubbles) |

## Border Styles

On glass surfaces, borders use `var(--glass-border)`. On content surfaces, borders use `var(--border)`. Adjust opacity, not lightness.

## Rules

1. **Children are rounder than parents (or equal).** If a container has `--radius-lg`, items inside it should use `--radius-md` or smaller. This creates visual nesting.
2. **Inner radius = outer radius − padding.** When an element with border-radius contains a child that also has border-radius, the inner radius should be reduced by the padding between them to maintain optically consistent curves. If the padding exceeds the outer radius, the inner radius can be `--radius-sm` or zero.
3. **Borders are 1px only.** All borders are `1px solid`. Thicker borders are reserved for focus indicators (`2px outline`). Never use 3px+ borders.
4. **Border opacity over border color.** On glass surfaces, borders use `var(--glass-border)`. On content surfaces, borders use `var(--border)`. Adjust opacity, not lightness.
