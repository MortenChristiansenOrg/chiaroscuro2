# Borders & Radius

## Border Radius Scale

| Value | Usage |
|-------|-------|
| `6px` | Tab close button |
| `8px` | Nav buttons, URL copy button, window controls, content panel, workspace controls |
| `12px` | URL pill, pinned icons, app mockup container |
| `16px` | Cards |
| `20px` | Tabs (pill-shaped) |
| `50%` | Favicons, workspace bubbles |

## Border Styles

| Color | Usage |
|-------|-------|
| `oklch(1 0 0 / 0.07)` | Separator lines, ephemeral divider |
| `oklch(1 0 0 / 0.08)` | Subtle panel borders |
| `oklch(0.92 0 0)` | Page nav border (light content) |
| `oklch(0.93 0 0)` | Card borders |
| `oklch(0.94 0 0)` | Hero section border, footer border |

All borders in the glass UI use white with very low opacity (`0.07–0.08`). Content panel borders use light gray oklch values.
