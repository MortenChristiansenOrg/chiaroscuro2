# Typography

## Font Stacks

| Role | Family | Fallback |
|------|--------|----------|
| Primary UI | Plus Jakarta Sans | sans-serif |
| Labels & Small Text | DM Sans | sans-serif |
| Code / Mono | JetBrains Mono | monospace |

## Size Scale

All sizes from the D8 mockup:

| Token | Size | Usage |
|-------|------|-------|
| `page-hero-h1` | 36px | Page hero headings |
| `page-nav-title` | 20px | Navigation title |
| `page-card-h3` | 14px | Card headings |
| `page-body` | 13.5px | Hero description text |
| `tab-text` | 12.5px | Sidebar tab labels |
| `tab-small` | 12px | Smaller tab variants |
| `url-text` | 11px | URL bar, page links |
| `favicon-text` | 10px | Pinned icon favicon text |
| `label` | 9px | Section labels (BOOKMARKED, etc.) |
| `ws-label` | 10px | Workspace bubble text |
| `eph-clear` | 9px | "Clear" button text |
| `switcher-label` | 7px | Smallest text (design switcher) |
| `favicon-char` | 8px | Favicon character |

## Weights

| Weight | Value | Usage |
|--------|-------|-------|
| Regular | 400 | Body text, inactive tabs |
| Medium | 500 | Active tabs, labels, section headers |
| Semibold | 600 | Favicon characters, workspace bubbles |

## Letter Spacing

| Value | Usage |
|-------|-------|
| `-0.01em` | Page nav title |
| `0.02em` | URL text, clear button |
| `0.1em` | Section labels, page links |
| `0.15em` | Page section labels |
