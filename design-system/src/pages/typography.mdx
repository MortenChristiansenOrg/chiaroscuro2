# Typography

## Font Stack

| Family | Variable | Usage |
|--------|----------|-------|
| Plus Jakarta Sans | `--font-sans` | All UI text: tabs, labels, headings, body |
| JetBrains Mono | `--font-mono` | Code, URLs, keyboard shortcuts |

Only two font families. No DM Sans — Plus Jakarta Sans covers all UI needs.

## Size Scale

Sizes in rem. Chrome context uses the compact end; content context uses the full range.

| Token | Size | Weight | Tracking | Usage |
|-------|------|--------|----------|-------|
| `--text-xs` | `0.5625rem` (9px) | 500 | `0.1em` | Section labels, uppercase tags |
| `--text-sm` | `0.6875rem` (11px) | 400 | `0.01em` | URL text, secondary info, metadata |
| `--text-base` | `0.75rem` (12px) | 400 | `0` | Tab text, sidebar items, default chrome text |
| `--text-md` | `0.875rem` (14px) | 500 | `-0.01em` | Card titles, section headings in content |
| `--text-lg` | `1.25rem` (20px) | 600 | `-0.015em` | Page titles in content areas |
| `--text-xl` | `2.25rem` (36px) | 600 | `-0.02em` | Hero headings (rare — content pages only) |

## Rules

1. **Maximum 3 sizes per context.** Chrome UI should use at most `--text-xs`, `--text-sm`, and `--text-base`. Content panels add `--text-md` and `--text-lg`. `--text-xl` is reserved for heroes.
2. **Two weights in chrome: 400 and 500.** Regular for default state, medium for active/emphasized. Use 600 only in content headings or tiny dense text (workspace bubble letters) where extra weight aids legibility.
3. **Tracking scales inversely with size.** Large text gets negative tracking (tighter). Small text gets positive tracking (looser, especially with `text-transform: uppercase`). Non-negotiable for readability.
4. **Line height.** Chrome elements: `1` or `1.15` (single-line, vertically centered via flex). Content body text: `1.6`–`1.7`. Never specify line-height on chrome UI elements that use flex centering.
5. **No font-size below `0.5625rem` (9px).** Anything smaller is illegible at standard DPI and fails accessibility.
6. **Monospace for literal content only.** URLs, code snippets, keyboard shortcut hints. Never for labels or body text.
