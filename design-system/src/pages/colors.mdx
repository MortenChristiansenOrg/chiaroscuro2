# Colors

All colors use the oklch color space for perceptual uniformity. The palette is split between mockup-specific "glass" colors and the shadcn semantic token system.

## Wallpaper Gradient

Background gradient behind the glass UI:

```css
background: linear-gradient(150deg,
  oklch(0.45 0.09 270) 0%,
  oklch(0.38 0.08 250) 30%,
  oklch(0.33 0.09 230) 55%,
  oklch(0.40 0.07 200) 80%,
  oklch(0.42 0.06 260) 100%);
```

## Shadcn Semantic Tokens

The app also uses shadcn/ui's CSS variable system for standard UI components. See `main.css` `:root` and `.dark` blocks for the full set (background, foreground, card, popover, primary, secondary, muted, accent, destructive, border, input, ring, sidebar variants).

| Token | Light | Dark |
|-------|-------|------|
| `--background` | `oklch(1 0 0 / 0.7)` | `oklch(0.145 0 0)` |
| `--foreground` | `oklch(0.145 0 0)` | `oklch(0.985 0 0)` |
| `--primary` | `oklch(0.205 0 0)` | `oklch(0.985 0 0)` |
| `--muted` | `oklch(0.97 0 0)` | `oklch(0.269 0 0)` |
| `--border` | `oklch(0.922 0 0)` | `oklch(0.269 0 0)` |
| `--destructive` | `oklch(0.577 0.245 27.325)` | `oklch(0.396 0.141 25.723)` |
