# Spacing

Spacing values extracted from the D8 Baseline mockup. No formal spacing scale yet — values are ad-hoc per component.

## Common Padding Values

| Value | Usage |
|-------|-------|
| `5px 0 0` | Sidebar top padding |
| `0 6px 2px` | Pinned strip padding |
| `5px 12px` | Tab horizontal padding |
| `1px 6px` | Tab margin (creates gutter) |
| `4px 14px` | Folder header padding |
| `10px 12px` | Workspace bar padding |
| `6px 8px 4px 14px` | Ephemeral divider padding |
| `2px 6px` | Clear button padding |
| `20px 40px` | Page nav padding |
| `60px 40px 48px` | Page hero padding |
| `32px 40px 16px` | Section label padding |
| `0 40px 48px` | Cards grid padding |
| `14px 16px` | Card body padding |

## Gap Values

| Value | Usage |
|-------|-------|
| `1px` | Nav button gap |
| `2px` | Window controls gap, workspace control gap |
| `6px` | Pinned strip gap, workspace bubble gap |
| `8px` | Ephemeral divider gap |
| `10px` | Tab icon-to-text gap |
| `16px` | Card grid gap |
| `20px` | Page nav links gap |

## Notes

As components are implemented, these values should be consolidated into a small spacing scale (e.g., 2/4/6/8/10/12/14/16/20/24/32/40/48/60px). For now, this page serves as a reference of what the mockup actually uses.
