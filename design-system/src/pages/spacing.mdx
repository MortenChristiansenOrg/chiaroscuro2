# Spacing

All spacing uses `rem`. Base: `1rem = 16px` (browser default). Never use px for spacing in component styles.

## The Scale

Only these values are permitted. No in-between values.

| Token | Value | Semantic meaning |
|-------|-------|------------------|
| `0.125rem` | 2px | **Hairline** — optical adjustments, icon-to-text nudges |
| `0.25rem` | 4px | **Tight** — elements that are parts of the same control (icon + label in a button) |
| `0.375rem` | 6px | **Related** — siblings within the same group (tabs in a list, buttons in a toolbar) |
| `0.5rem` | 8px | **Grouped** — items that belong together but have individual identity (sidebar sections, form fields) |
| `0.75rem` | 12px | **Sectioned** — separation between logical groups within a region |
| `1rem` | 16px | **Regional** — padding of major containers, gap between distinct UI areas |
| `1.25rem` | 20px | **Distinct** — separation between unrelated regions |
| `1.5rem` | 24px | **Major** — page-level section separation |
| `2rem` | 32px | **Page** — top-level structural spacing in content areas |

## Rules

1. **Gap for siblings, padding for containers.** Use CSS `gap` between items that are peers. Use `padding` for breathing room inside a container around its children.
2. **Proximity = relationship.** If two elements are closer together, the user perceives them as related. Use the semantic meaning column to choose spacing.
3. **Chrome is denser than content.** The sidebar, titlebar, and toolbar use the tight end of the scale (`0.25rem`–`0.75rem`). Content pages and settings use the wide end (`1rem`–`2rem`).
4. **Consistent axis spacing.** Horizontal and vertical spacing within a component should use the same token or adjacent tokens. Don't pair `0.25rem` horizontal with `1.5rem` vertical.
5. **Margin is a last resort.** Prefer gap and padding. Use margin only for one-off positional adjustments (e.g., `margin-top: auto` to push an element to the bottom of a flex container).

## Don'ts

- Never use `0.3rem`, `0.6rem`, `0.9rem`, or any value not in the scale.
- Never use `px` for spacing. The only exception: `1px` borders and `1px` separator lines.
- Never add spacing "because it looks a bit empty." Density is intentional.
