# Chiaroscuro Design System

The visual language for Chiaroscuro — a personal browser built on Electron. This system documents design tokens, patterns, and components extracted from the D8 "Baseline" mockup.

## Design Philosophy

- **Glassmorphism**: Translucent layers with backdrop blur over a gradient wallpaper
- **oklch color space**: All colors defined in oklch for perceptual uniformity
- **Pill-shaped elements**: Tabs, URL bar, and workspace bubbles use generous border-radius
- **Subtle depth**: Minimal box-shadows, hover lifts, and animated borders
- **Plus Jakarta Sans**: Primary UI typeface with DM Sans for labels
